# VocaMaps — versión clara (B)

Esta es la versión con fondo blanco y estilo sencillo de proyecto escolar.

## Cómo usarla
- Descarga el ZIP y descomprímelo.
- Abre `index.html` en Chrome o Edge o con Live Server de Visual Studio Code.
- Escribe el nombre de un salón o servicio, elige el piso y haz clic en el resultado.
- El mapa 3D se conserva del proyecto anterior y se maneja con el mouse o con gestos táctiles.

**El mapa 3D requiere internet** para cargar Three.js. El buscador y el directorio funcionan sin esa descarga.

## Para ponerla en GitHub Pages
1. Entra al repositorio que ya usas para VocaMaps.
2. Sube el nuevo `index.html` y reemplaza el anterior.
3. Guarda los cambios (Commit changes).
4. Abre la dirección de GitHub Pages que ya tenías. El mismo enlace y QR siguen funcionando si no cambiaste la URL.

Esto es un prototipo estudiantil y no un plano oficial. Las ubicaciones se siguen ajustando conforme se comprueban en el edificio.
